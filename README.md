# react_gim

## Опис проекту  
`react_gim` — це простий фронтенд-додаток, створений з використанням React.  
Мета: демонстрація/реалізація інтерфейсу за допомогою React.  

## Основні функції  
- Базова структура React-застосунку: компоненти, стан, події.  
- Пошук клієнтів
- Фільтрація клієнтів
- Надання статусу
- Модульність
- Сучасний веб-стек: React + JavaScript + CSS.
